Spotkanie 6: R i GitHub Copilot CLI

Spotkanie 6 z 6 · treść programowa 7

Instalujesz GitHub Copilot CLI w planie Free i sprawdzasz jego pomoc przy statystykach, wielkości efektu oraz poprawianiu kodu.

Plan 90 minut: 20 min instalacja i logowanie, 20 min podsumowanie liczbowe, 25 min wielkość efektu, 20 min korekta kodu, 5 min kontrola.

Pobierz szablon 06. GitHub Copilot CLI działa w terminalu i wymaga konta GitHub. To inne narzędzie niż Microsoft Copilot Chat z organizacji. GitHub potwierdza dostępność CLI w planie Copilot Free; plan Free ma ograniczony miesięczny przydział użycia. Nie trzeba wykupować płatnego planu do wykonania zajęć.

Learn — z prowadzącym

Ćwiczenie 20. Instalacja i bezpieczne uruchomienie

Cel

Uruchomisz asystenta CLI w folderze kursowym i poznasz granice jego dostępu.

Zadanie

Aktywuj GitHub Copilot Free na koncie GitHub, zainstaluj CLI, uruchom je w terminalu projektu i zaloguj się.

  1. Zaloguj się na GitHub własnym kontem i włącz Copilot Free, jeżeli nie masz aktywnego planu.
  2. W RStudio lub Positronie otwórz Terminal w folderze projektu. W Windows, w PowerShell 6 lub nowszym, wykonaj winget install GitHub.Copilot. Gdy winget nie jest dostępny, zgodnie z instrukcją instalacji GitHub można użyć Node.js 22 lub nowszego i npm install -g @github/copilot. Na innych systemach wybierz metodę z tej samej instrukcji.
  3. Sprawdź instalację przez copilot version, a potem uruchom copilot. Jeśli narzędzie poprosi o logowanie, wpisz /login i postępuj zgodnie z poleceniami.
  4. Zatwierdź zaufanie tylko do folderu tego projektu. Przeczytaj każde żądanie odczytu, uruchomienia polecenia lub zmiany pliku przed zgodą. Instrukcja użycia CLI wyjaśnia dostęp narzędzia do plików. Zakończ przez /exit.

Nie wklejaj haseł, tokenów ani danych osobowych. Korzystaj z fikcyjnego zbioru kursowego. Jeżeli instalacja lub logowanie nie powiedzie się w czasie zajęć, wykonaj obliczenia samodzielnie w R i zapisz, który etap CLI sprawił trudność; pokażesz go prowadzącemu podczas konsultacji.

Kryteria sukcesu

Wiesz, czym różnią się dwa konta Copilot, widzisz wersję CLI i potrafisz uruchomić oraz zamknąć sesję we właściwym folderze.

Ćwiczenie 21. Podsumowanie liczbowe z kontrolą

Cel

Poprosisz CLI o wskazówkę do kodu, ale liczby obliczysz i sprawdzisz w R.

Zadanie

Zapytaj CLI o kod dla liczebności, średniej, mediany i odchylenia czasu obsługi według grupy. Nie podawaj gotowych liczb w promptcie.

Przykładowe polecenie w interaktywnej sesji CLI: „W pliku R Markdown pracuję z ramką zgloszenia_analiza. Podaj krótki kod R liczący n, liczbę braków, średnią, medianę i sd dla czas_min według grupa. Nie zgaduj wyników. Pokaż test sumy liczebności i wyjaśnij na.rm.”

Porównaj propozycję z tym szkieletem i uruchom własny kod:

statystyki <- zgloszenia_analiza |>
  dplyr::group_by(grupa) |>
  dplyr::summarise(
    n = dplyr::n(),
    braki = sum(is.na(czas_min)),
    srednia = mean(czas_min, na.rm = TRUE),
    mediana = median(czas_min, na.rm = TRUE),
    sd = sd(czas_min, na.rm = TRUE),
    .groups = "drop"
  )
statystyki
sum(statystyki$n)

Sprawdź, czy suma n daje 240 oraz czy n - braki odpowiada liczbie obserwacji użytych do średniej. W tekście podaj wynik po uruchomieniu kodu, nie z odpowiedzi CLI.

Kryteria sukcesu

Raport zawiera tabelę dla A i B, poprawne liczebności i własną kontrolę; wiadomo, która sugestia pochodziła z CLI.

Ćwiczenie 22. Wielkość efektu i interpretacja

Cel

Obliczysz standaryzowaną różnicę średnich i sprawdzisz interpretację asystenta.

Zadanie

Oblicz d Cohena dla czasu w grupach A i B z połączonym odchyleniem standardowym. Zapytaj CLI, co oznacza znak i jednostka wyniku, a odpowiedź porównaj z własnym kodem. 

a <- na.omit(zgloszenia_analiza$czas_min[
  zgloszenia_analiza$grupa == "A"])
b <- na.omit(zgloszenia_analiza$czas_min[
  zgloszenia_analiza$grupa == "B"])
sd_pooled <- sqrt(((length(a) - 1) * var(a) +
                   (length(b) - 1) * var(b)) /
                  (length(a) + length(b) - 2))
d_cohena <- (mean(a) - mean(b)) / sd_pooled
c(n_A = length(a), n_B = length(b),
  roznica_min = mean(a) - mean(b), d = d_cohena)

Przykładowe pytanie do CLI: „Wyjaśnij znak i znaczenie d Cohena obliczonego jako (średnia A − średnia B) / połączone SD. Jak sprawdzić liczebności i czy z tej wielkości wolno wnioskować o przyczynie? Nie podawaj arbitralnej etykiety mały/duży bez kontekstu.”

Sprawdź, że znak d_cohena jest taki sam jak znak surowej różnicy średnich i że sd_pooled > 0. Efekt jest bez jednostki; różnica średnich jest w minutach. Nie utożsamiaj wielkości efektu z wartością p.

Kryteria sukcesu

Raport podaje liczbę obserwacji, różnicę w minutach, d Cohena, kierunek i ograniczenie interpretacji.

Challenge — samodzielnie

Ćwiczenie 23. Napraw kod i audytuj sugestię

Cel

Samodzielnie rozpoznasz błąd w kodzie, użyjesz CLI do diagnozy i sprawdzisz poprawkę.

Zadanie

Poniższy kod zawiera błędną nazwę kolumny oraz pomija obsługę braków. Poproś CLI o wyjaśnienie obu problemów bez modyfikowania pliku. Następnie napisz własną poprawioną wersję w raporcie, uruchom ją i porównaj z wynikiem ćwiczenia 21. 

# Kod do diagnozy; pokaż w .Rmd z eval=FALSE:
zgloszenia_analiza |>
  dplyr::group_by(grupa) |>
  dplyr::summarise(srednia = mean(czas_minn))

W końcowym .Rmd zapisz: fragment błędny, krótką diagnozę CLI, poprawiony kod, wynik własnej kontroli i jedno zdanie, którego sugestii asystenta nie przyjąłeś lub co dodatkowo sprawdziłeś. Nie pozwalaj CLI wykonywać zmian bez przeczytania propozycji. Jeżeli limit planu Free się wyczerpie, wykonaj diagnozę samodzielnie i opisz test.
